02 Grammar (EBNF)

program    ::= statement* EOF
statement  ::= letStmt | assignStmt | ifStmt | whileStmt | printStmt | block
letStmt    ::= "let" IDENT "=" expr ";"
assignStmt ::= IDENT "=" expr ";"
ifStmt     ::= "if" "(" expr ")" statement ( "else" statement )?
whileStmt  ::= "while" "(" expr ")" statement
printStmt  ::= "print" "(" expr ")" ";"
block      ::= "{" statement* "}"

expr       ::= unary ( BINOP expr )*      -- precedence climbing, table below
unary      ::= "-" unary | "not" expr₃ | primary
primary    ::= NUMBER | "true" | "false" | IDENT | "(" expr ")"

-- else-if needs no special rule: the else branch is itself an ifStmt.
-- The dangling else binds to the nearest if.

03 Operator precedence

The parser reads binary operators from a precedence table instead of one grammar rule per level. To parse at level p, it reads a unary operand and then takes operators with precedence ≥ p. Each right operand is parsed at prec + 1, which makes every operator left-associative.

05 Error handling

Panic-mode recovery

On a syntax error the parser records a diagnostic, then skips tokens until it passes a ; or reaches let if while print { }. Then it continues, so one run reports every error.

Caret diagnostics

Every error carries a line, column and length. Missing ; / ) are reported just past the previous token, where they belong.

Helpful notes

Hints for common mistakes: = in a condition (did you mean ==?), ! → not, and unclosed { with the opening position.

Four phases

lexical (bad characters), syntax (grammar), semantic (scopes) and runtime (division by zero, infinite-loop guard).

06 Semantics

  • Two value types: integers and booleans. Arithmetic needs integers. / and % truncate toward zero, as in C.
  • { } opens a new scope. The body of an if or while always gets its own scope.
  • A variable must be declared with let before use, and cannot be redeclared in the same scope. Inner scopes may shadow outer ones.
  • Conditions accept booleans or integers (non-zero is true). and / or short-circuit.
  • The interpreter stops after 200,000 steps to guard against infinite loops.
